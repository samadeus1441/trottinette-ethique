# Trottinette Éthique — Lyon

Site-manifeste de la campagne citoyenne **Charte de la Trottinette Éthique** à Lyon et dans sa métropole.

## À propos

Ce projet propose :

- Une **charte du Trottinetteur Responsable** avec 8 principes concrets.
- Un **formulaire de signature** local (stockage navigateur).
- Une **pétition** avec 3 demandes adressées aux collectivités.
- Un **kit média** pour les journalistes et influenceurs locaux.
- Des **sources et données** (HCL, plan Beaune 2023, chartes Lyon/Paris).

## Tech stack

- [Next.js 14](https://nextjs.org/) (App Router)
- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## Développement local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Build & déploiement

```bash
npm run build
```

Le site est exporté statiquement dans le dossier `dist/`.

Pour déployer sur Vercel :

```bash
vercel --prod
```
